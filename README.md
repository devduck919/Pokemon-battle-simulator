# Details
Program allows users to add, create, and edit Regions, Trainers, and pokemon from a selection of 20 pokemon given the pokedex.txt file.
Allows users to cutomize pokemon team from individual trainers and have them go up against each other with their respective pokemon partners.
Code detects whether pokemon is weak or resistant to oppenents pokemon type.
Exceptions are handled when parameters needed to battle/edit features when they are not met.
